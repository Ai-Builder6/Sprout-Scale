Phase 1: Connect sprout-scale.com to Cloud Run (HTTPS)

  1. Click Deploy / Share in AI Studio so the newest SproutScale build (with https://sprout-scale.com/?install=1 and /og-share-1200x630.png) is deployed to Cloud Run.
  2. Open Google Cloud Run → Domain Mappings (project bookmycleaning-tidyups-v001).
  3. Click Add Mapping → choose your SproutScale service → map sprout-scale.com. Repeat for www.sprout-scale.com.
  4. In your domain registrar's DNS Zone for sprout-scale.com:
    • Delete any old parking / "Coming Soon" A, AAAA, or CNAME records on @ and www.
    • Add the exact A and AAAA records shown by Cloud Run for @.
    • Add the CNAME record for www pointing to ghs.googlehosted.com.
  5. Wait 10–45 minutes for Cloud Run to show a green SSL checkmark, then confirm https://sprout-scale.com/ loads SproutScale with a valid padlock.

Phase 2: Approve sprout-scale.com in Firebase & Google OAuth

  1. Open Firebase Authentication → Settings → Authorized domains.
  2. Add sprout-scale.com and www.sprout-scale.com.
  3. Open Google Cloud Credentials → open OAuth Client 509716171565-mfan543u4mv1lvee97hupkovlk201nh2.apps.googleusercontent.com.
  4. Under Authorized JavaScript origins, add https://sprout-scale.com and https://www.sprout-scale.com, then click Save.

Phase 3: Verify sprout-scale.com in Meta Business Suite

Do not skip this step! Domain verification is the #1 way to prevent Meta Ads rejections and link editing blocks.
  1. Go to Meta Business Settings → Brand Safety and Suitability → Domains.
  2. Click Add → Create a new domain → enter sprout-scale.com.
  3. Choose Update the DNS TXT record with your domain registrar and copy the facebook-domain-verification=... code.
  4. In your domain registrar DNS settings, add a TXT record with Host @ and paste the code.
  5. Wait 5–15 minutes, then click Verify Domain in Meta until it turns green.
  6. Click Connected Assets → Assign Assets and connect your SproutScale Facebook Page.

Phase 4: Verify Meta Pixel (1701764191622077) & Traffic Permissions

  1. Open Meta Events Manager and select Pixel 1701764191622077 (already installed live in SproutScale).
  2. Go to Settings → Traffic Permissions → Create allow list and add sprout-scale.com and www.sprout-scale.com.
  3. Open Test Events, enter https://sprout-scale.com/, click Open Website, and confirm a green PageView event fires.
  4. In Meta Business Settings → Data Sources → Datasets & Pixels, assign your Ad Account to Pixel 1701764191622077.

Phase 5: Configure Meta App in Meta for Developers

  1. Open Meta for Developers → Create App → name it SproutScale and link your Business Portfolio.
  2. Go to App Settings → Basic and enter the exact URLs from the table at the top of this page.
  3. Upload icons/01-meta-app-icon-1024x1024.png as the App Icon.
  4. Click + Add Platform → Website and enter Site URL: https://sprout-scale.com/.
  5. Under Facebook Login → Settings → Valid OAuth Redirect URIs, enter: https://sprout-scale.com/auth/meta/callback.
  6. Save changes and toggle App Mode from Development to Live.
